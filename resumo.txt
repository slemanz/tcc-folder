----------------------------------------------------------------------------------------------------------------

Neste trabalho são exploradas as capacidades do Open CPU do módulo NINA-B306, desenvolvendo um dispositivo para aquisição de dados, destinado ao registro da temperatura ambiente. O trabalho visa demonstrar as funcionalidades e aplicabilidades do módulo no contexto de sistemas embarcados. O estudo tem como objetivo geral compreender os aspectos técnicos do NINA-B306, que inclui a análise das suas especificações, a arquitetura interna, bem como as possibilidades de integração. A partir disso, é realizado a descrição das funcionalidades básicas do módulo, a investigação da metodologia de arquitetura em camadas para a implementação do dispositivo, e o desenvolvimento de um prótotipo funcional em protoboard. Foi desenvolvido um dispositivo, dividido em camadas de hardware, software e aplicação, onde o dispositivo faz a aquisição de dados da temperatura ambiente de tempo em tempo e armazena em uma memória, podendo realizar diversas leituras de dados para extração posterior utilizando uma interface serial para USB com o auxilio de um computador. O trabalho além de demonstrar as capacidades do módulo, apresenta uma metodologia para desenvolvimento de sistemas embarcados, visando não utilizar nenhum tipo de framework, assim tendo uma profundide e entendendo o que acontece por trás dos panos, o que muita vez fica escondido em frameworks por conta de muita abstração. Todo código é aberto, podendo ser reutilizado e/ou melhorado por qualquer pessoa que tenha interesse.

-----------------------------------------------------------------------------------------------------------------

Este trabalho explora as capacidades do módulo NINA-B306, utilizando o seu Open CPU para desenvolver um dispositivo de aquisição de dados destinado ao registro da temperatura ambiente. O objetivo é demonstrar as funcionalidades e aplicações deste módulo no contexto de sistemas embarcados. O estudo analisa aspectos técnicos do NINA-B306, incluindo suas especificações e arquitetura. A partir dessa análise, descrevem-se as funcionalidades básicas do módulo e investiga-se a metodologia de arquitetura em camadas para implementar o dispositivo. Desenvolveu-se um protótipo funcional em protoboard, dividido em camadas de hardware, software e aplicação. O dispositivo realiza a aquisição de dados de temperatura em intervalos regulares, armazenando as leituras em memória externa. Os dados podem ser extraídos posteriormente por meio de uma interface serial USB, com o auxílio de um computador e um programa em Python. Além de demonstrar as capacidades do módulo, o trabalho propõe uma metodologia para o desenvolvimento de sistemas embarcados, evitando o uso de frameworks e permitindo uma compreensão mais profunda do funcionamento interno de um microcontrolador, frequentemente oculto devido à abstração. Todo o código do módulo foi desenvolvido em linguagem de programação C e é de código aberto, permitindo que qualquer pessoa interessada o reutilize em outras aplicações e até proponha melhorias nas soluções apresentadas. Além de ter toda documentação em inglês, para assim poder alcançar um maior número de pessoas.

Palavras-chave: Sistemas Embarcados; Open CPU; Aquisição de Dados; Arquitetura em Camadas.
